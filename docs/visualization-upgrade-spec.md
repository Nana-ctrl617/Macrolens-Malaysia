# Chart-led dashboard refinement

Replace text-heavy first views with meaningful, interactive comparisons on Risk, Brief, Households, Balance of Payments and Forecast. Preserve the compact sans-serif design, existing calculations, payload schema 9/8, daily data pipeline, public URL, observation dates, sources and stale/fallback warnings.

Risk and Households: show existing 0–100 rule-based pressure scores in a selectable colour matrix and common-scale horizontal bars. Scores are not probabilities; do not invent history or change calibration. Selected evidence and all detailed rules remain available.

Brief: show actual indicator history with series/range controls, dated point inspection, source/unit labels, and an accessible table. First/last changes are descriptive and do not claim causation. Keep the brief text in progressive disclosure.

BOP: show actual quarterly account history and the latest signed account balances around a zero line. Respect accounting signs, missing observations and official sources. Do not label all negative flows bad.

Forecast: compare MAE/RMSE on one percentage-point scale, retain selected-model and backtest explanations, intervals and sensitivity functions. Lower error is better, not a guarantee.

No illustrative or invented observations, new data sources, images, chart dependencies, forecasts, investment instructions, risk history or schema upgrade. Hover, touch and keyboard inspection must expose exact values without relying only on colour. Mobile must contain plots and keep controls readable.
